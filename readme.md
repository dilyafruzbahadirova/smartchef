T1 — жаңа рецепт оқылады, сақталады және қайта ашылады.
T2 — steps жоқ/бос/қате, қате JSON, бос жауап не провайдер қатесі: рецептсіз, сақтаусыз және дайындауға кірмей түсінікті бас тарту.
T3 — ескі рецепт пен ескі session draft: мәтін/сақтау жұмыс істейді, тексерілмеген қадамдар пайда болмайды.
T4 — бір қадам: Артқа өшірулі; растау аяқтайды; қос басу 2-қадамды жасамайды.
T5 — бірнеше қадам: артқа және қайта растау прогресті екі рет санамайды; соңында бос қадам жоқ.
T6 — басқа рецепт, шығу, draft сақтау және қайта бастау: күй тасымалданбайды.
T7 — RU/KK, пернетақта, ұзын сөздер және <script> мәтін ретінде; 375 px-де артық ен жоқ, батырмалар ≥44 px.
T8 — Lab5 каталогы, іздеу және сақтау жұмыс істейді; Git ішінде .env, кілттер, SQLite, .venv және жүктемелер жоқ.

## №7: AI редакторы және режимдер
SmartChef №7 сақталған құрылымды рецептке AI ұсынысын жасап, оны түпнұсқамен салыстыруға, Accept/Reject арқылы қабылдауға не кері қайтаруға және соңғы Accept өзгерісін бір деңгей Undo арқылы қалпына келтіруге мүмкіндік береді.
Бұл архивте жеке Demo/Live ауыстырғышы іске асырылмаған: AI ұсынысын жасау үшін нақты Gemini API кілті қажет (Live), ал провайдерсіз тексеру тесттерде mock арқылы жүргізіледі (Demo тестілеу тәсілі).
